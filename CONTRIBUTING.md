# Contributing

This SDK is generated from `Bidsketch/signwell-sdk-generator`.

Please do not edit generated runtime, API, model, or package metadata files
directly in the published SDK repo. Durable SDK fixes should be made in the
generator templates, spec hooks, or Python overlay files, then regenerated.

Open issues for bugs, missing types, broken serialization, or SDK ergonomics at:

https://github.com/Bidsketch/signwell-sdk-python/issues
