# FileFormat

Format of the file to be downloaded. Supported formats are 'pdf' and 'zip'. `zip` is unavailable on a 21 CFR Part 11 document, whose completed PDF, E-Signature page and audit page stay together as one record.

## Enum

* `PDF` (value: `'pdf'`)

* `ZIP` (value: `'zip'`)
