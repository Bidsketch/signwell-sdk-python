# DateFormat

Date format for date fields. Valid values: MM/DD/YYYY, DD/MM/YYYY, YYYY/MM/DD, Month DD, YYYY, MM/DD/YYYY hh:mm:ss a. Default: MM/DD/YYYY

## Enum

* `MM_SLASH_DD_SLASH_YYYY` (value: `'MM/DD/YYYY'`)

* `DD_SLASH_MM_SLASH_YYYY` (value: `'DD/MM/YYYY'`)

* `YYYY_SLASH_MM_SLASH_DD` (value: `'YYYY/MM/DD'`)

* `MONTH_DD_COMMA__YYYY` (value: `'Month DD, YYYY'`)

* `MM_SLASH_DD_SLASH_YYYY_HH_COLON_MM_COLON_SS_A` (value: `'MM/DD/YYYY hh:mm:ss a'`)
